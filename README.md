# 📸 A Modern Social Feed Built with Next.js

A full-featured social feed web app built with **Next.js 14**, **TypeScript**, and **Tailwind CSS** featuring post creation, image/video uploads, likes, comments, and infinite scrolling.  
This project demonstrates a **production-ready social feed** architecture using the latest **App Router** and **Server Actions**.

## Features

### Core

- Login Auth
- Feed

### Under the Hood

- Next.js 16
- React Compiler
- Tailwind CSS

## Getting Started

First, run the development server:

```bash
npm run dev

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
